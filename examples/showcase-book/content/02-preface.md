# Preface

A publication pipeline becomes useful when the same source can survive several destinations without losing structure. This showcase starts as Markdown and project assets in GitHub, then passes through one PubForge compiler into a paginated Vivliostyle preview, PDF-oriented print rendering, EPUB 3 and a Web Publication.

The chapters deliberately mix semantic roles, figures, tables, notes, internal links, math and data resources. The goal is not visual excess. The goal is to make hidden assumptions visible.

> A good publishing test is not a screenshot. It is a small book that makes the renderer prove what it understands.

The next chapter tests [typography and semantic markup](03-typography.md#ruby-and-language). Later we cross-reference [the mathematical model](05-math-links.md#the-model) from another document, which verifies document-link rewriting.
