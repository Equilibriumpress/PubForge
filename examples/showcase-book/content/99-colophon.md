# Colophon

**The Browser Book** was assembled as a PubForge regression publication.

Source is stored in GitHub. The active commit is the reproducible edition identifier used by PubForge at render time.

### Tested outputs

- Vivliostyle paginated preview
- browser PDF print view
- EPUB 3
- Web Publication ZIP
- source snapshot ZIP

### Design

The print theme uses system serif and sans-serif families so the repository does not need to redistribute font binaries. The publication nevertheless exercises embedded-asset handling through vector graphics and project resources.

End of showcase.
