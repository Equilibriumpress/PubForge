# Studio notes

:::columns{count="3" gutter="5mm"}
A magazine page is built from contrast: image and text, density and quiet, repetition and interruption. The page should feel composed without becoming rigid.

:::pullquote
Good editorial layout changes pace before it changes decoration.
:::

The three-column body tests flowing copy. Pull quotes should interrupt without destroying reading order, and the same semantic content should still collapse sensibly in reflowable EPUB.

:::sidebar
### Design rule

Use one dominant move per page. A large image, an oversized quote or an unusual grid is usually enough.
:::

The final section introduces a small image gallery. In print it sits as a grid; in reflowable output it remains a sequence of figures.
