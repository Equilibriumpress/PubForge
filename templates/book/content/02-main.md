# Margins and Memory

The second chapter demonstrates mirrored pages and running content. On left-hand pages the chapter title sits outward; on right-hand pages it moves to the opposite edge.

## Notes and references

A footnote can sit behind the sentence rather than inside it.[^note] In EPUB it becomes semantic note content; in paged output it can be styled more compactly.

[^note]: This showcase uses DPUB-style footnotes from VFM.

## A short list

1. Keep the text block stable.
2. Let chapter openers breathe.
3. Use decoration sparingly.
4. Keep navigation semantic.
