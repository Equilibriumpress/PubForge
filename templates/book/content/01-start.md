# The Quiet Room

> A page begins before the first word: with proportion, silence and expectation.

<p class="lead">A book page is a small architectural space. The margins establish distance, the type sets a pace, and the first paragraph teaches the reader how the rest of the chapter wants to be read.</p>

Good book design rarely announces itself. It creates continuity. Running heads help orientation without interrupting the page. Folios sit at the edge of attention. Paragraphs form a grey value that should remain calm across a spread.

## Rhythm

The line length is deliberately moderate. Paragraphs use widow and orphan control, while chapter openings start on a recto page. The first paragraph receives a drop cap only in print-like layout; the semantic text remains ordinary HTML for EPUB.

A second paragraph makes the texture visible. It contains enough words to demonstrate justification, hyphenation and the relationship between paragraph spacing and first-line indents. A reader should notice the argument, not the machinery that holds it together.
